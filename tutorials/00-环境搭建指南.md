# 教程 00:环境搭建指南(Windows,Day 1-2)

> 对应计划 Phase 1 环境部分。目标:2 天内全部跑通,每完成一项打勾。

## 1. 安装 Git

1. 下载:https://git-scm.com/download/win
2. 安装时一路默认(勾选默认组件即可,"Git Bash" 会顺带装好)
3. 打开 PowerShell(开始菜单搜 "PowerShell")验证:
   ```powershell
   git --version
   ```
4. 配置身份(你每次提交都会带上这个名字):
   ```powershell
   git config --global user.name "你的名字"
   git config --global user.email "你的邮箱"
   ```

## 2. GitHub + SSH Key

1. 注册 https://github.com (用户名建议用拼音,以后放简历上)
2. 生成密钥(PowerShell 执行,一路回车):
   ```powershell
   ssh-keygen -t ed25519 -C "你的邮箱"
   ```
   默认生成到 `C:\Users\你的用户名\.ssh\id_ed25519`
3. 查看公钥并复制:
   ```powershell
   Get-Content $env:USERPROFILE\.ssh\id_ed25519.pub
   ```
4. GitHub 网页 → 右上头像 → Settings → SSH and GPG keys → New SSH key → 粘贴保存
5. 验证:
   ```powershell
   ssh -T git@github.com
   ```
   看到 "Hi 你的用户名! You've successfully authenticated..." 即成功。

## 3. Miniconda + 虚拟环境

1. 下载:https://docs.conda.io/en/latest/miniconda.html (Windows 64-bit)
2. 安装后打开 **Anaconda Prompt**(开始菜单搜 anaconda)
3. 创建项目环境并激活:
   ```bash
   conda create -n llm python=3.11 -y
   conda activate llm
   python --version
   ```
4. 日常命令:
   ```bash
   conda activate llm      # 激活
   conda deactivate        # 退出
   conda env list          # 查看所有环境
   pip install 包名        # 在激活的环境里装包
   ```

## 4. VS Code + 扩展

1. 下载:https://code.visualstudio.com
2. 打开 Extensions(快捷键 Ctrl+Shift+X),安装:
   - **Python**(Microsoft)
   - **Jupyter**
   - **GitLens**(看 git 历史)
   - **Markdown Checkboxes**(勾选本计划的任务)
   - **Markdown Preview Enhanced**(预览 md)
3. File → Open Folder → 选择 `D:\plan`
4. Ctrl+Shift+P → 输入 "Python: Select Interpreter" → 选择 llm 环境的 python

## 5. GPU 检查与 PyTorch 安装

1. PowerShell 运行:
   ```powershell
   nvidia-smi
   ```
   - 正常显示 = 有 NVIDIA 显卡,表格第一列是型号(如 RTX 3060)、显存大小
   - 提示"不是内部或外部命令" = 没有驱动或没有独显,直接看第 6 节
2. 打开 https://pytorch.org → 按你的系统选 **Stable / Windows / Pip / Python / CUDA 版本**(CUDA 版本选小于等于你驱动支持的,一般选 12.x 即可)→ 复制给出的命令,在 Anaconda Prompt(llm 环境)执行,例如:
   ```bash
   pip3 install torch torchvision --index-url https://download.pytorch.org/whl/cu121
   ```
3. 验证(最关键一步):
   ```bash
   python -c "import torch; print(torch.__version__, torch.cuda.is_available())"
   ```
   打印出 `True` 即成功。

## 7. PowerShell 常用命令速查

| 命令 | 作用 |
|---|---|
| `cd D:\plan` | 进入目录 |
| `dir`(或 `ls`) | 列出文件 |
| `mkdir 文件夹名` | 建目录 |
| `Get-Content 文件名` | 查看文本文件 |
| `python 脚本.py` | 运行脚本 |
| `pip list` | 查看已装包 |
| `cls` | 清屏 |

> 建议主要用 Anaconda Prompt 跑 python/pip/conda,用 PowerShell 跑 git 和文件操作。
