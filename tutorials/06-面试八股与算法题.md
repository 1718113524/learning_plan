## 一、Transformer 面试题(20 问)

**1. 自注意力的计算过程与复杂度?**
Q=WqX,K=WkX,V=WvX → softmax(QKᵀ/√d)V。复杂度 O(n²d)(n 序列长,d 维度),内存也是 O(n²)。

**2. 为什么除以 √d?**
Q、K 每个元素方差为 d,点积后方差 ≈ d,值域变大 → softmax 饱和、梯度消失。除以 √d 把方差拉回 1。

**3. 多头注意力为什么有效?**
不同头在不同子空间建模不同模式(语法、指代、位置关系),相当于集成多个"关注角度";且并行可算。

**4. self-attention 与 cross-attention 的区别?**
self:Q/K/V 来自同一序列;cross:Q 来自目标序列,K/V 来自源序列(decoder 里 Q 来自 decoder,K/V 来自 encoder 输出)。

**5. LayerNorm 和 BatchNorm 的区别?为什么 Transformer 用 LN?**
BN 在 batch 维归一化,依赖 batch 大小,序列长度不一时很麻烦;LN 在特征维归一化,与 batch/序列长度无关,逐样本独立 → 适合 NLP、适合小 batch、推理时行为与训练一致。

**6. 为什么用 pre-norm(先 LN 再子层)?**
梯度传播更稳、可训更深的网络;post-norm(原始论文)需要更精细的 warmup,pre-norm 训练更鲁棒。GPT 系列都是 pre-norm。

**7. 位置编码:绝对 vs 相对 vs RoPE?**
- 绝对:正弦/可学习,直接加在 embedding 上;长度外推差
- 相对:建模 token 间距离(T5、ALiBi)
- **RoPE**:旋转位置编码,通过旋转矩阵把位置信息注入 Q/K,点积只依赖相对位置,外推能力好 → 现在主流(LLaMA、Qwen 都用)

**8. 残差连接的作用?**
恒等映射 + 分支学习增量:缓解梯度消失,让深层网络可训;残差分支初始接近 0,模型从"近似恒等"开始学,更稳定。

**9. 训练和推理的区别?**
训练:teacher forcing 并行算所有位置(因果 mask 挡住未来),算 loss 反传;推理:自回归逐个生成,用 KV cache 复用历史。

**10. KV cache 是什么?显存占多少?**
推理时每步把已算好的历史 K/V 缓存,新 token 只算自己的 QKV,省掉重复计算。显存 = 2 × 层数 × 头数 × 头维 × 序列长 × 精度字节。瓶颈在长文本:1M 上下文 × 80 层 8B 模型 → 数百 GB,所以才有各种 KV cache 压缩。

**11. MHA / MQA / GQA 区别?**
MHA 每头独立 KV;MQA 所有头共享一份 KV(省显存但伤质量);GQA 折中:分组共享(LLaMA2 用 8 组),省显存同时保持质量。

**12. Flash Attention 是什么?**
IO-aware 精确注意力:把 QKV 分块搬到 SRAM 里算,避免把 O(n²) 注意力矩阵写回 HBM。数学结果不变,显存 O(n)、速度 2-4 倍。不改变结果,不是近似算法(除分块误差)。

**13. GELU 和 ReLU 的区别?**
ReLU 在 0 点不可导、负区间梯度为 0;GELU 平滑近似(x·Φ(x)),负区间有小梯度,处处可导,Transformer 标配。

**14. GPT-2 参数量怎么算?**
≈ 12·d²·L + vocab·d(embedding/lm_head 共享)。d=768, L=12, vocab=50257 → ≈ 85M + 39M ≈ 124M。

**15. 为什么 GPT 用因果 mask?**
语言模型要"预测下一个词",每个位置只能看自己和过去,防止信息泄露(否则等价于抄答案),这也是自回归生成的前提。

**16. pre-norm 下,残差分支的初始化为什么缩放 1/√(2N)?**
N 层残差堆叠,每层输出方差会累加;把残差分支的输出初始化得更小(σ=0.02/√(2N)),让初始网络近似恒等、信号方差稳定。

**17. 多头里 QKV 的拼接怎么拆?**
c_attn 输出 3d,split 成 Q/K/V 各 d,再 view+transpose 成 (B, head, T, d/head)。这个操作你已经在教程 03 手写过,面试时直接背出来。

**18. dropout 加在哪?**
GPT-2:attention 权重后、resid 输出后、MLP 后(嵌入后也加)。推理时全部关闭。

**19. 为什么 transformer 比 RNN 好?**
并行计算(无顺序依赖)、长程依赖直接建模(attention 一步可达)、容量大;代价是 O(n²) 复杂度和位置信息需要额外编码。

**20. 长文本怎么处理?**
RoPE 外推(linear/ntk/yarn 插值)、滑动窗口/稀疏注意力(Longformer、Mistral)、分段 + 全局记忆、KV cache 压缩(GQA/量化/丢弃)。

## 二、大模型八股(10 问,后训练岗重点)

**1. pretrain → SFT → RLHF 各自的作用?**
预训练学语言建模与知识;SFT 学对话格式与指令遵循;RLHF 对齐人类偏好(有用性、无害性、诚实性),学"什么是好回答"。

**2. LoRA 为什么有效?参数量公式?**
低秩假设(见教程 04 第 2 节);参数量 = r×(d_in+d_out)×矩阵数。r=8 时通常只有全参的千分之几。α 与 r:实际缩放 α/r。

**3. LoRA 的 r 和 alpha 怎么调?**
r 太小(1-2)表达能力不足,8-64 常用;alpha 常设 2r。效果不佳就扩大 target_modules 或 r,别急着全参微调。

**4. QLoRA 的三个关键技巧?**
NF4 量化(信息论最优 4bit 分桶)+ 双重量化(量化常量再量化)+ paged optimizer(优化器状态分页防 OOM)。

**5. DPO 和 PPO 的区别?怎么选?**
DPO:偏好对直接优化,免 RM、免采样,稳定便宜,工业界常用;PPO:在线采样 + RM 打分 + KL 约束,覆盖广上限高但复杂。选型:数据/算力有限用 DPO,关键模型上 RL(PPO/GRPO 系)。

**6. 为什么 RLHF 需要 reference model / KL 惩罚?**
防止策略为刷奖励分而崩溃(说废话、讨好、重复),KL 约束不让新策略离 SFT 模型太远,保住语言能力。

**7. 量化的基本概念?GPTQ/AWQ 区别?**
把 fp16 权重映射到低位宽(int8/int4);PTQ(训后量化)vs QAT(训练中量化)。GPTQ:基于 OBQ 的二阶(海森)逐层量化;AWQ:激活感知,保护对输出影响大的通道(scale 放大再量化)。

**8. 分布式训练的几种并行?**
DP:复制模型分数据;DDP:DP+梯度 AllReduce 同步;TP:按层内矩阵切分(Megatron,通信密集);PP:按层切分(GPipe,有气泡);ZeRO:切分优化器状态/梯度/参数(数据并行的内存优化)。大模型 = 3D 混合(TP×PP×DP)。

**9. 幻觉的原因与缓解?**
原因:最大似然目标不惩罚编造、训练数据有噪声、长尾知识记不住、解码采样随机性。缓解:RAG 给证据、CoT 增强推理、约束解码、SFT 对齐诚实性(教模型说不知道)。

**10. SFT 数据怎么构造?**
来源多样(开源指令集+自己写)、覆盖目标能力、指令清晰、输出高质量且风格统一、去重去污染(不能混入测试集)、配比均衡。数据质量 >> 数量。

## 三、机器学习基础(8 问)

1. **过拟合怎么判断和解决**:train 好 val 差;解决 = 更多数据/增强、正则(L1/L2/dropout)、早停、降模型容量。
2. **L1 vs L2**:L1 产生稀疏解(特征选择),L2 收缩权重(平滑);都是加惩罚项到 loss。
3. **BN 原理**:对每个特征在 batch 内归一化 + 可学习 scale/shift,缓解内部协变量偏移、加速收敛、允许更大 lr。
4. **SGD/Momentum/Adam/AdamW**:Adam = 动量 + 自适应学习率(二阶矩),收敛快;AdamW 把 weight decay 从梯度里解耦,泛化更好(现在默认 AdamW)。
5. **评估指标**:acc;precision/recall/F1(不平衡分类);AUC(排序能力,阈值无关);回归 MSE/MAE。
6. **类别不平衡**:重采样、类别权重、focal loss、阈值调整、评估用 F1/AUC 而非 acc。
7. **梯度消失/爆炸**:深层链式求导,激活饱和(消失)或权重过大(爆炸);缓解 = BN/残差/合理初始化/梯度裁剪。
8. **为什么用交叉熵不用 MSE 做分类**:交叉熵 + softmax 梯度 = p-y,误差大梯度大,收敛快;MSE 会饱和、梯度小。
